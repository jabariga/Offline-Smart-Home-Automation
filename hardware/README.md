# Hardware

This folder contains the hardware design files, circuit diagrams, component list, and wiring documentation for the offline smart home automation system.

## Main Components

- Arduino Uno R3 Microcontroller
- Relay Module
- Temperature and Humidity Sensor
- Bluetooth Communication Module
- LCD (20X4) &  (16X2)
