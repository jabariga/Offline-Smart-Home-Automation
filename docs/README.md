## Overview

This project presents a low-cost offline smart home automation framework designed to improve convenience, security, and environmental monitoring within residential environments.

Unlike cloud-based smart home systems, this solution operates entirely offline using Bluetooth communication between an Android application and an ESP32 microcontroller. This approach reduces deployment cost, improves privacy, and allows the system to continue functioning without Internet connectivity.

The project integrates home security, environmental monitoring, and appliance automation into a single embedded system.

## Features

- Bluetooth-based appliance control
- Offline operation
- Home security monitoring
- Temperature monitoring
- Humidity monitoring
- Air quality monitoring
- Relay-based appliance switching
- Android mobile application
- Low-cost hardware
- Energy-efficient design
